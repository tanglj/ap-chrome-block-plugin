# TBlock

一个简单易用的 Chrome 网站屏蔽插件，支持按域名或特定页面进行屏蔽。

## 功能特性

- 🚫 **域名屏蔽** - 屏蔽整个域名的所有页面
- 📄 **页面屏蔽** - 仅屏蔽特定的页面
- 🔴 **实时状态指示** - 被屏蔽的页面在插件图标上显示红色徽章标记（显示 "B"）
- ⚡ **快速添加** - 一键添加当前页面或当前网站到屏蔽列表
- 🎨 **简洁界面** - 直观的用户界面，易于操作

## 安装方法

1. 下载或克隆此项目到本地
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目文件夹

## 使用说明

### 添加屏蔽规则

1. **手动添加**
   - 点击插件图标打开弹窗
   - 在输入框中输入网站域名或页面 URL
   - 选择屏蔽模式（整个域名 / 特定页面）
   - 点击"添加"按钮

2. **快速添加**
   - 点击插件图标打开弹窗
   - 点击"添加当前页面" - 仅屏蔽当前页面
   - 点击"添加当前网站" - 屏蔽整个域名

### 移除屏蔽规则

1. 点击插件图标打开弹窗
2. 在"已屏蔽的网站"列表中找到要移除的网站
3. 点击"删除"按钮

## 图标说明

- **默认图标** - 当前页面未被屏蔽
- **红色徽章 "B"** - 当前页面已被屏蔽

## 技术实现

- 使用 Chrome `declarativeNetRequest` API 进行请求拦截
- 使用 `chrome.action.setBadgeText` 和 `setBadgeBackgroundColor` 显示状态徽章
- 数据存储在 `chrome.storage.local` 中

## 权限说明

- `storage` - 存储屏蔽列表
- `declarativeNetRequest` - 网络请求拦截
- `activeTab` - 获取当前标签页信息
- `tabs` - 管理所有标签页的图标状态
